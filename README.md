# Creator Cache

**Creator Management & Cost Intelligence Platform**

Creator Cache is a full-stack web application designed to streamline creator management and cost-related workflows within the influencer marketing ecosystem.

The platform centralises creator-related operational information into a unified application, helping teams manage data and improve workflow efficiency.

## Overview

Managing creator information and associated costs across multiple workflows can introduce operational complexity and fragmented data.

Creator Cache addresses this by providing a centralised platform for creator cost management, built around practical business requirements and operational workflows.

## Key Highlights

- Full-stack application built using the MERN stack.
- Centralised creator cost management.
- Designed for real-world business workflows.
- Adopted by 50–200 active users.
- Developed from the ground up, covering frontend and backend engineering.

## System Architecture

Creator Cache follows a client-server architecture, with a React frontend communicating with a Node.js backend through API endpoints.

```text
             Users
               |
               v

               |

          API Layer
               |
               v
        Node.js Backend
               |
               v
            Database
```
